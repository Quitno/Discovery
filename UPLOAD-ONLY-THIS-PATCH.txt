PATA MAHALI — FULL PROJECT RESTORE PACKAGE

This folder is a complete project source tree, not a small overlay patch. It includes app.py, templates/, static/, requirements.txt, Procfile, render.yaml, and supporting source files.

UPLOAD / DEPLOY
1. Extract the project ZIP.
2. Copy every file and folder from the extracted project root into the ROOT of the existing PataMahali GitHub repository, replacing matching code/assets and preserving the folder structure.
3. Do not create a nested Discovery-main/Discovery-main directory. app.py and requirements.txt must sit at the repository root.
4. Commit and let Render redeploy from GitHub.
5. Keep existing Render environment variables and persistent disk. Do not delete or overwrite /var/data, the production database, uploaded listings/photos, identity documents, or secrets. This project ZIP intentionally does not contain your production database.

KEY FIXES IN THIS BUILD
- Shared navigation links no longer call the fragile about_patamahali URL endpoint; public About/help links use their stable paths.
- The error template no longer extends base.html, so a broken shared navigation endpoint cannot turn the 404/500 page into another 500.
- /favicon.ico redirects to the current PataMahali SVG icon and is excluded from visitor tracking/backups.
- Find goes to /homes; Post goes to /partner/dashboard for signed-in partners or /partner/register for new partners.
- The hidden mobile category drawer stays out of normal document flow, removing the large blank area above search results.
- The hut-shaped default mark is replaced by a location-pin/target icon in SVG, PNG/PWA, and social preview assets.
- The service-worker cache version is bumped so corrected styles and scripts can load after deployment.
