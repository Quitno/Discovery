CLEAR DATA PRACTICES

Privacy, in plain language.

This page explains the basic data handled by {{ site_settings.site_name }}.

Account information

When you register, we store your name, email address, a securely hashed password, plan orders, subscription dates and API key records so the service can work.

Site visits and anonymous visitor IDs

We record public page views, the page path, approximate network address (the final IPv4 segment is masked), referrer path and browser user-agent. A random first-party browser ID is stored in a cookie for up to one year so repeat visits from the same browser profile are usually counted as the same anonymous visitor. This ID is not a fingerprint of the physical device and does not identify you by itself. Clearing cookies, using private browsing or switching browser profiles can create a new anonymous ID. Admin pages, static assets and API calls are excluded from the visitor page-view list.

Payments

For manual payment verification, we store the payer name, phone number, amount, transaction code and review status. We do not ask for your M-Pesa PIN or one-time password. A payment reference is not automatically proof of payment.

Product data

Product information may include barcodes, names, brands, pack sizes, categories, prices, sources and verification status. A price may vary by retailer and date. Verification labels reflect the catalogue's recorded status and should not be taken as a guarantee unless an authoritative source has been checked.

Contact and choices

For questions or data correction requests, contact the support address shown on this website when configured. Access credentials should not be shared. API keys can be revoked from your account. You can remove the anonymous visitor cookie by clearing this site's cookies in your browser.

Before public launch, add your approved legal business details, a working support contact, retention periods and any additional notices required for your operations.
